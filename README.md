# 🚀 LeetCode SQL 50 Solutions

This repository contains my solutions to the **LeetCode SQL 50 Study Plan**, designed to strengthen SQL fundamentals and prepare for Data Analyst, Business Analyst, Data Engineer, and SQL Developer interviews.

## 📌 About

The SQL 50 Study Plan covers:

- Basic SELECT Statements
- Filtering and Sorting
- Aggregate Functions
- GROUP BY & HAVING
- Joins
- Subqueries
- Window Functions
- Common Table Expressions (CTEs)
- Advanced SQL Concepts

All solutions are written in **MySQL** and optimized for readability and interview preparation.
